# Banana Memory Game

Banana Memory Game is an interactive browser-based memory matching game developed using JavaScript.

## Features
- Card matching logic
- Score tracking
- Lives system
- Timer-based gameplay
- Level progression
- Banana API integration
- User authentication
- Sound effects
- Version control using Git

## Technologies Used
- HTML
- CSS
- JavaScript
- Banana API
- Git & GitHub

## How to Run
Open index.html in a web browser.
